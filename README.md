# 花蓮縣中低收入戶與低收入戶統計 BI 網頁

把衛生福利部統計處的「中低收入戶／低收入戶戶數及人數按鄉鎮市區別分」報表，整理成可以互動篩選的 BI 網頁。

- 網頁：https://ha074.github.io/hw3/
- 資料來源：衛生福利部統計處
- 資料期間：中華民國 115 年（2026）第 1 季底、第 2 季底
- 地區：花蓮縣 13 個鄉鎮市

## 目錄

```
中低1.0.xlsx           原始報表（未修改）
work/build_data.py     ETL：讀取報表 → 輸出 docs/data.js
work/verify_data.py    驗證：data.js 與原始報表逐格比對、加總核對
docs/index.html        BI 網頁（GitHub Pages 從 docs/ 發佈）
docs/data.js           ETL 輸出的資料，網頁用 <script> 載入
```

## ETL 做了什麼

原始報表在同一張工作表裡有兩張表（中低收入戶、低收入戶），表頭是四層合併儲存格：季度 → 戶數／人數 → 性別 → 年齡層。

- 依合併儲存格的範圍，把每個數值對應到正確的季度、統計項目、性別與年齡層。
- 只保留最細的明細：鄉鎮市 × 性別（戶數）、鄉鎮市 × 性別 × 年齡層（人數）。
- 排除「總計」列、「花蓮縣」合計列，以及所有「計／總計」小計欄，避免重複加總；網頁上的合計一律由明細相加。
- 數值為 0 的資料保留。
- 中低收入戶表有第 3、4 季的表頭，但原表沒有數值，因此不輸出，也不補值。

## 驗證

`work/verify_data.py` 會用與 ETL 不同的讀法重新讀取報表，檢查：

- data.js 每一筆數值都等於原始儲存格，沒有遺漏、多出或重複的分類。
- 各鄉鎮明細相加等於報表本身的「計／總計」欄。
- 13 個鄉鎮相加等於報表的「花蓮縣」合計列，例如中低收入戶 115 年第 1 季：2,453 戶、4,823 人。

## 重新產生與驗證

需要 [uv](https://docs.astral.sh/uv/)：

```
uv run work/build_data.py
uv run work/verify_data.py
```

## 使用限制

- 戶數、人數都是「季底」數字。跨季相加會重複計算同一戶或同一人，所以年齡層分佈與地區比較兩張圖只取所選季度區間的最後一季。
- 報表的戶數只分性別、沒有年齡層。
- 中低收入戶表最上方的「總計」列（例如第 1 季 89,201 戶）不等於花蓮縣各鄉鎮的合計，報表沒有說明它的統計範圍，因此沒有採用。
- 網頁從 cdnjs 載入 ECharts 5.5.0，需要網路連線。
