## 2. 用 AI 對 PDF 做 ETL

課堂上做 ETL 的是 Excel。這題的對象是 61 頁的 PDF：114 學年上學期的休學人數統計表。

```text
請用 Python + uv，把「東華大學統計資料/休學人數統計表/114學年上學期.pdf」轉成整齊的 CSV。

輸出：
- CSV 存到 work/leave_114-1.csv，編碼 UTF-8 with BOM
- 程式存到 work/etl_leave.py

規則：
- 每一列是一個「系所 × 學制 × 性別 × 身份類別 × 休學原因」，欄位為
  dept_raw, program_raw, gender, identity, reason, new_leave, on_leave_end
- new_leave 是「學期間休學人數」，on_leave_end 是「於學期底處於休學狀態之人數」，兩者都依休學原因分開
- reason 用以下名稱：傷病、經濟困難、學業成績不佳、就讀學校科系不符期待、工作、懷孕、育嬰、兵役、出國、論文撰寫、就學環境、家務或家人照顧、考試訓練、其他、違反校規、其他（勒令）
- 兩個人數都是 0 的列可以省略
- 排除表格最上方的「本表總數」列，但可以用它來檢查你的加總
- 注意儲存格內的文字會換行，例如「應用數」「學系」要合併成「應用數學系」

完成後執行：
uv run scripts/validate.py leave work/leave_114-1.csv
如果有不符，找出原因並修正。
```
