# P0 開始（10 分鐘）

## 1. 用 template 建立自己的 repo

1. 打開 https://github.com/samsonchen/ndhu-bi-demo-template
2. 按右上角綠色的 **Use this template** → **Create a new repository**
3. Owner 選自己的帳號，Repository name 例如 `ndhu-bi`，選 **Public**
4. 按 **Create repository**

## 2. 把 repo 下載到電腦，啟動 Claude Code

打開終端機（macOS：Terminal；Windows：PowerShell），把 `<你的帳號>` 換成自己的 GitHub 帳號：

```
gh repo clone <你的帳號>/ndhu-bi
cd ndhu-bi
claude
```

Claude Code 執行過程中會詢問是否允許執行指令或修改檔案，這堂課都選 **Yes**。

## 3. 第一個 prompt

```text
請讀這個 repo 的 README.md，用 5 句話以內告訴我：這個 repo 有哪些資料、放在哪裡、這堂課要做出什麼。不要修改任何檔案。
```

---

改一改（選做）：問 Claude「data/leave.csv 裡 114-1 學期間休學人數最多的前 3 個系所是哪些？」看它怎麼找答案。
