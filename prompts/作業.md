# 作業：用自己找的資料做 BI 網頁

自己找一份公開的統計資料，用課堂上 P0～P3 的做法，做 ETL、做互動 BI 網頁，再用 GitHub Pages 發佈。

本次作業由 AI 評分。繳交方式、合規條件、主題佔用和評分標準的完整規則，請看 [chapter_2 評分說明](https://github.com/samsonchen/ai_workshop_assets/tree/main/chapter_2)（[student-guide](https://github.com/samsonchen/ai_workshop_assets/blob/main/chapter_2/student-guide.md)）。下面的要求是依照那份規則訂的。

AI 給的是參考分數，最終成績由授課老師決定。

## 1. 找資料

資料要自己找，不能用課堂上東華大學的在學、休學人數資料做和講師示範一樣的分析。

可以從這些地方開始找：

- [政府資料開放平臺](https://data.gov.tw/)
- [內政部戶政司 人口統計資料](https://www.ris.gov.tw/app/portal/346)
- [行政院主計總處](https://www.dgbas.gov.tw/)
- [交通部觀光署 觀光統計](https://admin.taiwan.net.tw/)
- [教育部統計處](https://depart.moe.edu.tw/ED4500/)
- 各縣市政府的開放資料平臺

「資料來源 + 主題」的寫法舉例（只是示範格式，不是建議題目）：

- 資料來源：內政部戶政司｜各縣市人口數按性別及年齡
- 主題：各縣市 65 歲以上人口比例的地區差異

選題前先想清楚：

- 主題是先繳交先佔用。同一組「資料來源 + 主題」別人用了，你就不能用。
- 找的資料最好是原始檔（Excel、CSV、PDF），可以整份放進 repo。

## 2. 建 repo

- 另外開一個新的 public repo 做作業，不要用課堂的 repo。
- repo 大小不要超過 200 MB。

## 3. 作業要求

依評分項目整理，每一項都做到會比較有分數。

**ETL**

- 原始檔、ETL 程式、處理後的輸出，三樣都要放在 repo。原始資料不在 repo，ETL 最多 1 分。
- 不要手抄資料。
- 有驗證（例如加總核對）或有處理合併儲存格、名稱變更這類髒資料，可以拿到更高分。

**圖表**

- 單位、加總要正確，不要用會誤導的圖型。
- 有軸標題、單位、註腳，圖上的數字要和資料一致。

**互動與洞察**

- 至少要有篩選或切換。
- 多張圖連動，或有講師示範以外的分析角度，可以拿到更高分。

**呈現與說明**

- 網頁上寫清楚資料來源、資料期間、限制說明。
- 手機打開要能讀。

AI 會看電腦和手機寬度的全頁截圖，以及 repo 裡的原始資料、ETL 程式、輸出。每個檔案只讀前 200 KB，Excel 只看前 200 列。AI 不會上網查證你的資料來源，也不會執行你的程式。

## 4. 繳交

1. Discord 開啟「允許伺服器成員私訊」，沒開不會評分。
2. 把 GitHub Pages 網址貼到 claude.formosa Server 的 **#ndhu-ba-2026** channel，例如 `https://你的帳號.github.io/你的repo/`。
3. 結果會用私訊傳給你。可以修改後重傳，每次分數都會記錄。

只有 `https://<帳號>.github.io/...` 的網址會被處理。`github.com/...` 的連結不算繳交。

對評分有疑問，先看私訊裡的理由和截圖，再找老師。
