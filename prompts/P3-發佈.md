# P3 發佈到 GitHub Pages（10 分鐘）

## Prompt

```text
請把所有變更 commit 並 push 到 GitHub。
接著用 gh 開啟這個 repo 的 GitHub Pages，來源設為 main branch 的 /docs 資料夾。
完成後告訴我網頁網址。
```

## 如果 Claude 沒辦法開啟 Pages，手動設定

1. 到自己 repo 的 GitHub 頁面 → **Settings** → **Pages**
2. Source 選 **Deploy from a branch**
3. Branch 選 `main`，資料夾選 `/docs`，按 **Save**

網址是 `https://<你的帳號>.github.io/<repo 名稱>/`，第一次發佈要等 1～2 分鐘。
